# Project ownership

Enaptic owns its native package-management UI, backend adapter, pending marks
and transaction review. APK remains the native solver and transaction engine.
AlpinE owns distro/package feed configuration; theme-kit owns reusable artwork.
Sharing visual direction does not create runtime dependencies on E-Jamz.

Synaptic is the concrete interaction reference. Blue-metal styling may follow
the E projects, while tables, labels and status stay readable and conventional.
Use native widgets for dense administrative controls; dot-LCD fonts are not
required for package names, descriptions or transaction output.

Prototypes must distinguish fixtures, cached data and current backend results.
Never present a marked request as the solver’s accepted transaction.
